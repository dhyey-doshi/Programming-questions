## 🛠️ Contribution & Naming Convention

When adding a new solution:
1. Place the solution file inside the corresponding platform folder (e.g. `LeetCode/0001-two-sum.py` or `LeetCode/Two_Sum/solution.cpp`).
2. Include problem details, approach, and time/space complexity in comments at the top of the solution file.
3. Commit with a descriptive message:
   ```bash
   git commit -m "Add solution for LeetCode #1: Two Sum"
   ```
